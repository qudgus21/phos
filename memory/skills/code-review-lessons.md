# 코드 리뷰 교훈

### 1. withAuth HOF의 쿠키 전파 주의
- **상황**: Supabase `@supabase/ssr`에서 세션 갱신 쿠키를 설정할 때, HOF 내부 response와 handler 반환 response가 다른 객체일 수 있음
- **교훈**: 쿠키를 별도 배열에 저장한 뒤 핸들러 응답에 전파해야 토큰 갱신이 클라이언트에 반영됨
- **날짜**: 2026-02-24

### 2. 렌더링 중 setState 호출 패턴
- **상황**: ref로 이전 값을 비교하면서 렌더링 본문에서 setState를 호출하는 패턴
- **교훈**: React 18에서는 렌더링 중 setState가 동기적 재렌더링을 유발하며 무한 루프 위험. 반드시 useEffect로 이동
- **날짜**: 2026-02-24

### 3. 디자인 시스템 색상 일관성
- **상황**: CSS 변수 기반 디자인 시스템이 있지만 일부 컴포넌트에서 하드코딩 색상(slate-400, blue-500 등) 사용
- **교훈**: 새 컴포넌트/수정 시 반드시 CSS 변수 매핑 색상 사용 여부 확인. 특히 LoginModal, Navigation, Hero 등 초기 구현 파일에 하드코딩이 많음
- **날짜**: 2026-02-24

### 4. 에디터 패널 코드 중복 패턴
- **상황**: face-edit, image-edit, retouching 에디터가 MobileTabs, 슬라이더 스타일, 파일 업로드 등을 각각 독립 구현
- **교훈**: 에디터 기능 추가 시 기존 에디터와의 공통 컴포넌트 추출 기회를 먼저 확인
- **날짜**: 2026-02-24
