3. 크레딧의 두 가지 종류

구독 크레딧

매월 결제 시 충전되는 크레딧

  • 매달 결제 시 기존 잔액에 새 크레딧 추가 (누적)
  • 구독을 취소해도 소멸하지 않음 — 다 쓸 때까지 유지 (단, 취소 시 다음 달 새 충전은 없음)
  • 크레딧 사용 시 일회성 크레딧 다음으로 차감
일회성 크레딧

크레딧 팩 구매로 획득하는 크레딧

  • 소멸 없이 영구 보유
  • 구독 상태와 완전히 무관
  • 크레딧 사용 시 먼저 차감됨
  • 구독 없이(Free 상태)도 구매 가능
크레딧 차감 순서
이미지를 생성하면 일회성 크레딧이 먼저 사용되고, 부족하면 구독 크레딧에서 차감됩니다.
예: 일회성 50 + 구독 2,000 보유 → 80크레딧 사용 시 → 일회성 50 + 구독 30 차감 = 잔액 일회성 0 + 구독 1,970

4. 기본 시나리오

4-1. 신규 구독 즉시 적용

🛒 Free 사용자가 Basic 플랜을 구독
사용자가 가격표에서 Basic "시작하기" 클릭
Polar 결제 페이지로 이동 → 카드 정보 입력 → $9 결제
결제 완료 → Polar가 웹훅으로 "결제 완료" 알림 전송
웹훅 핸들러가 DB 업데이트: 플랜 → Basic, 구독 크레딧 → 2,000
결과: 즉시 Basic 혜택 사용 가능 (쿨다운 없음, 배치 4장)

4-2. 구독 갱신 (자동 결제) 크레딧 누적

🔄 매월 자동 갱신
결제일이 되면 Polar가 자동으로 카드 청구
결제 완료 웹훅 도착
기존 잔액 + 새 크레딧으로 누적
결과: 예) Basic: 잔액 300 + 갱신 2,000 = 2,300
결제한 크레딧은 소멸하지 않습니다
매달 결제하는 만큼의 크레딧이 기존 잔액에 추가됩니다. 이전에 남은 크레딧이 사라지지 않습니다.
일회성 크레딧도 당연히 영향 없습니다.

4-3. 업그레이드 즉시 적용

⬆️ Basic → Pro 업그레이드

예: Basic(2,000/월) 구독 중, 1,500 사용하여 잔액 500. 30일 중 15일 남음

사용자가 가격표에서 Pro "업그레이드" 클릭 → 확인 모달에서 승인
즉시 적용 — 다음 결제일을 기다리지 않음
남은 기간의 차액만 청구 (15일 남음 → 차액 $10의 50% = $5)
크레딧도 남은 기간에 비례하여 부여:
비례율 = 15일 / 30일 = 50%
Basic 비례 = 2,000 × 50% = 1,000
Pro 비례 = 4,400 × 50% = 2,200
추가 크레딧 = 2,200 - 1,000 = +1,200
새 잔액 = 500 - 1,000 + 2,200 = 1,700
결과: 플랜 → Pro, 구독 크레딧 → 1,700
업그레이드 크레딧 계산 (날짜 비례)
결제와 동일하게 남은 기간에 비례하여 크레딧을 부여합니다.
공식: 새 잔액 = 기존잔액 - (구플랜크레딧 × 비례율) + (새플랜크레딧 × 비례율)
결제 주기 첫날에 업그레이드하면 차액 전액, 마지막날에 하면 거의 0에 가깝습니다.

4-4. 다운그레이드 다음 달 적용

⬇️ Pro → Basic 다운그레이드
사용자가 가격표에서 Basic "다운그레이드" 클릭 → 확인 모달에서 승인
즉시 적용 안 됨 — "다음 결제일부터 적용" 예약만 등록
이번 달은 Pro 크레딧(4,400) 그대로 사용 가능
UI에 "다음 달부터 Basic 적용" 배지 표시
다음 결제일: 자동으로 Basic 적용 → $9 청구 → 기존 잔액 + 2,000 누적
결과: 이번 달은 Pro 유지, 다음 달부터 Basic

4-5. 구독 취소 크레딧 유지

❌ Premium 사용자가 구독을 취소

예: 4/1에 결제, 4/15에 취소. 구독 크레딧 5,000 남음.

사용자가 고객 포털 또는 가격표에서 "구독 취소"
구독 상태 → "취소됨" (canceled)
구독 크레딧 5,000은 그대로 유지 — 다 쓸 때까지 사용 가능
다음 달 결제일에 갱신/청구 없음 (새 크레딧 충전 없음)
결과: 남은 구독 5,000 + 일회성 크레딧을 모두 사용 가능. Premium 기능(쿨다운 없음, 배치 4장)도 그대로 유지
핵심 정책: 결제한 크레딧은 뺏어가지 않음
구독을 취소해도 이미 결제한 크레딧은 소멸하지 않습니다.
"구독 취소 = 다음 달 충전 안 됨"이지, "잔여 크레딧 삭제"가 아닙니다.
일회성 크레딧도 당연히 유지됩니다.

4-6. 취소 철회 (재구독)

🔄 취소한 구독을 다시 활성화
고객 포털에서 "취소 철회" 클릭
구독 상태 → "활성" (active)으로 복구
크레딧은 변경 없음 (취소 전과 동일한 잔액)
결과: 다음 결제일에 정상적으로 갱신됨. 크레딧 새로 충전

4-7. 구독 해지 (결제 실패) 크레딧 유지

🚫 결제 실패로 구독이 강제 해지
카드 만료, 잔액 부족 등으로 갱신 결제 실패
Polar가 재시도 후 최종 실패 → 구독 강제 해지(revoked)
Free 플랜으로 변경 (기능 제한: 쿨다운 5분, 배치 4장)
이전에 결제해서 받은 구독 크레딧은 유지 — 다 쓸 때까지 사용 가능
다음 달 새 충전만 없음
결과: 구독 크레딧 + 일회성 크레딧 모두 유지. 다시 구독하려면 새로 결제 필요
"취소"와 "해지"의 차이
취소 (canceled): 사용자가 직접 취소. 크레딧 유지 + 기능도 유지. 다음 달 충전만 안 됨.
해지 (revoked): 결제 실패. 크레딧 유지. 단, Free로 전환되어 기능 제한(쿨다운 5분, 배치 4장). 다음 달 충전 안 됨.
공통: 어떤 경우든 결제한 크레딧은 뺏지 않음.

4-8. 크레딧 팩 구매

💎 크레딧 팩(일회성) 구매
가격표에서 "일회성" 탭 선택 → 원하는 크레딧 팩 구매
Polar 결제 완료 → 웹훅으로 알림
결과: 일회성 크레딧에 즉시 추가. 영구 보유. 구독 상태와 무관

4-9. 환불

💸 전액 환불
관리자가 Polar에서 해당 주문에 전액 환불 처리
해당 주문으로 부여된 크레딧 회수 시도
이미 크레딧을 사용한 경우: 잔여분만 회수. 부족분(shortfall)은 기록
구독 주문 환불 시 → 구독도 함께 취소 처리
결과: 환불 금액 반환 + 크레딧 최대한 회수
💸 부분 환불
주문 금액의 일부만 환불 (예: $9 중 $4.5)
환불 비율에 비례하여 크레딧 회수 (50% 환불 → 50% 크레딧 회수)
구독은 유지됨 (부분 환불이므로)
결과: 여러 번 부분 환불이 와도 누적으로 정확하게 계산

4-10. 이미지 생성 (크레딧 사용)

🎨 이미지 생성 시 크레딧 차감

예: 일회성 30 + 구독 2,000 보유. 생성 비용 80 크레딧

생성 요청 → 쿨다운 체크 (Free: 5분, 유료: 없음)
크레딧 선차감: 일회성 30 + 구독 50 차감 (일회성 먼저, 부족분은 구독에서)
AI 모델로 이미지 생성
성공: 잔액 = 일회성 0 + 구독 1,950
실패 시: 일회성 30 + 구독 50을 각각 원래 풀로 복원 → 일회성 30 + 구독 2,000

5. 엣지 & 복합 시나리오

다양한 동작이 중첩될 때 시스템이 어떻게 동작하는지 상세히 설명합니다.

⬆️⬆️ 한 달 안에 두 번 업그레이드 (Basic → Pro → Premium)

Basic 시작(1일째) → 500 사용 → Pro 업그레이드(10일째, 20일 남음) → 1,000 사용 → Premium 업그레이드(20일째, 10일 남음)

Basic(2,000) 시작, 500 사용 → 잔액 1,500
Pro 업그레이드 (비례율 20/30 ≈ 67%): Basic비례 1,333 / Pro비례 2,933 → 잔액 = 1,500 - 1,333 + 2,933 = 3,100
Pro에서 1,000 사용 → 잔액 2,100
Premium 업그레이드 (비례율 10/30 ≈ 33%): Pro비례 1,467 / Premium비례 2,367 → 잔액 = 2,100 - 1,467 + 2,367 = 3,000
결과: 크레딧은 각 업그레이드 시점의 남은 기간에 비례. 결제도 동일하게 비례 청구
⬆️⬇️ 업그레이드 후 즉시 다운그레이드

Basic → Pro 업그레이드 → 바로 Basic으로 다운그레이드 요청

Pro 업그레이드 즉시 적용 → Pro 크레딧으로 재계산됨
Basic 다운그레이드 예약 → "다음 달부터 Basic" 표시
이번 달은 Pro 크레딧 그대로 사용
결과: 이번 달 차액 청구됨 + 이번 달은 Pro. 다음 달부터 Basic $9, 기존 잔액 + 2,000 누적
⬇️⬆️ 다운그레이드 예약 후 다시 업그레이드

Premium → Basic 다운그레이드 예약 → 마음 바꿔서 Premium 유지하고 싶음

Premium에서 Basic으로 다운그레이드 예약 완료
취소 철회(고객 포털) 또는 같은 플랜 재선택으로 예약 해제 가능
결과: 다운그레이드 예약이 해제되고, Premium 그대로 유지
⬇️❌ 다운그레이드 예약 후 구독 취소

Pro에서 Basic으로 다운그레이드 예약 → 그 후 구독 자체를 취소

Pro → Basic 다운그레이드 예약 상태
이후 구독 취소 → 다운그레이드 예약도 함께 해제됨 (다음 결제가 없으므로 의미 없음)
취소 철회(재구독) 시 → 다운그레이드 예약 없이 현재 플랜(Pro)으로 갱신
결과: 취소하면 다운그레이드 예약도 초기화. 재구독 시 깨끗한 상태
❌🔄 취소 후 재구독 (같은 플랜)

Premium 구독 취소 → 며칠 뒤 취소 철회

Premium 구독 취소 → 상태: canceled, 크레딧 유지
결제 기간 내에 고객 포털에서 "취소 철회" 클릭
상태: active로 복구. 크레딧 변경 없음
결과: 마치 취소한 적 없는 것처럼. 다음 결제일에 정상 갱신
❌🛒 취소 후 다른 플랜으로 신규 구독

Premium 구독 취소 → 결제 기간 만료 후 → Basic으로 새 구독

Premium 취소, 남은 크레딧 사용
결제 기간 만료 → 구독 크레딧 잔액 유지 (소멸 안 함)
Basic으로 새 구독 → 잔여 구독 크레딧 + 2,000 누적
결과: Basic 활성. 구독 크레딧 = 이전 잔액 + 2,000. 일회성 크레딧도 유지
💎❌ 크레딧 팩 구매 후 구독 취소

Pro 구독 중 1,500 크레딧 팩 구매 → 이후 구독 취소

현재 잔액: 구독 4,400 + 일회성 1,500 = 총 5,900
구독 취소 → 크레딧 전부 유지
크레딧 사용 시: 일회성 1,500 먼저 차감 → 이후 구독 4,400 차감
결과: 총 5,900 크레딧을 다 쓸 때까지 이용 가능. Pro 기능(쿨다운 없음, 배치 4장)도 유지
💸⬆️ 업그레이드 후 이전 주문이 환불되는 경우

Basic($9) 구독 → Pro 업그레이드 → 이후 Basic 주문에 대한 환불 발생
